# Pack de datos

Rellenar **antes** del workathon y entregar una copia por equipo (o un zip `tN-pack`).

| Fichero | Qué completar |
|---------|----------------|
| `rbac-matrix.csv` | Users, passwords temporales, roles |
| `team-sheet.md` | Org, URLs, prefijo |
| `scm.md` | Gitea URL, token, branch, webhook secret |
| `cloud.md` | AWS keys/rol, región, tags |
| `inventory-source.example.yml` | Source vars EC2 (Name + grupos linux/windows/web/db) |
| `hosts.md` | SSH/WinRM |
| `eda.md` | Event Stream URL, DE, JT apply-cac |

No commitear secretos reales a un repo compartido; usar un canal seguro el día del evento.
